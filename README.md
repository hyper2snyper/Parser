This was an attempt to make a mathematic parser that would evaluate expressions like (1+2)/(3/3+4(1+9)/8) and the like.
It marches through the string and constructs a tree, afterwards it will collapse the tree to get an answer.
I did this without any prior knowlege to compilers and such.
